支持将 4K 视频设为动态桌面壁纸，兼容 MP4、MOV 格式。只需把视频拖拽到应用界面，点击即可一键应用为桌面背景。

除本地视频外，还支持把摄像头画面、任意网页设置成桌面壁纸，为桌面带来生动有趣的动态效果。录制视频时搭配动态背景，也能让画面观感更加出彩。

我整理了一些优质的视频壁纸网站，点击链接即可下载。如果你有更好的推荐，欢迎通过邮件或提交 issue 与我分享：

- https://www.desktophut.com
- https://motionbgs.com
- https://moewalls.com
- https://mylivewallpapers.com
- https://wallsflow.com
